# Latha Vasupalli — Personal Portfolio

Welcome to my personal portfolio repository! This website showcases my academic background, technical skills, certifications, internships, and project work in cybersecurity and computer applications.

🌐 **Live Website:** [https://lathavasupalli.github.io/latha-portfolio/](https://lathavasupalli.github.io/latha-portfolio/)

---

## 🛠️ Built With

- **HTML5** — Semantic, accessible web structure
- **CSS3** — Custom modern dark cyberpunk aesthetic, flexbox/grid layout, smooth animations
- **JavaScript (ES6+)** — Matrix digital rain canvas effect, scroll reveal, dynamic navbar, interactive forms

---

## 📂 Project Structure

```text
latha-portfolio/
├── index.html       # Portfolio website structure and content
├── style.css        # Visual styling and responsive mobile/desktop rules
├── script.js        # Matrix background canvas and interactive logic
└── README.md        # Repository documentation
```

## 🚀 Running Locally

To view the website on your local machine:
1. Clone or download this repository:
   ```bash
   git clone https://github.com/lathavasupalli/latha-portfolio.git
   ```
2. Open `index.html` in any web browser.
